🎧 Camelot → Spotify

Import an ordered CSV into a new Spotify playlist. Your existing playlists are not changed.

1. Connect Spotify

Not connected

2. Choose CSV

Select your Camelot-ordered CSV. It must include Spotify track URIs or URLs.

3. Create playlist

Uses Spotify Authorization Code with PKCE. No client secret or third-party importer. Spotify developer access and API permissions are required. This app stores a temporary session token in your browser only. Don't upload private CSVs to public GitHub repositories.
